# Política de imágenes

Fuentes preferidas:
- Pexels
- Unsplash
- Pixabay
- Wikimedia Commons

Reglas:
1. No Google Images/Pinterest.
2. No usar material con marca visible que sugiera afiliación.
3. Preferir productos/alimentos genéricos.
4. Registrar URL directa, página de origen, fuente, autor, licencia/condición y fecha de verificación.
5. Si la procedencia/licencia no es verificable, NO usar.
6. No generar imágenes con IA.
7. Se permite `imagen_url` externa.
8. Debe existir fallback.
9. `docs/fuentes_imagenes.md` es evidencia obligatoria.
10. CP-LAND-04 falla si algún producto queda sin imagen verificada.

Performance:
- `loading="lazy"` fuera del hero;
- reservar dimensiones/aspect-ratio;
- evitar resoluciones mayores a las necesarias.
