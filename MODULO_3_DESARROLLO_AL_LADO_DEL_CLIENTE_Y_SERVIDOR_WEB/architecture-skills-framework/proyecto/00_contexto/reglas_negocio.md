# Reglas de negocio
- RN-01. Toda venta confirmada tiene un origen de inventario.
- RN-02. El stock no puede quedar negativo por una venta normal.
- RN-03. Las reservas web expiran según parámetro configurable.
- RN-04. Ajustes de inventario requieren usuario, motivo, fecha y auditoría.
- RN-05. La recepción de compras actualiza inventario solo al confirmarse.
- RN-06. Las transferencias tienen estados controlados.
- RN-07. Operaciones críticas expuestas a reintentos deben ser idempotentes.
- RN-08. Información transaccional confirmada no se elimina físicamente.
