# Sistema de ejemplo: tienda omnicanal de alimentos

La empresa vende alimentos en sucursales físicas y por Internet. Administra compras a proveedores, inventario compartido, ventas POS, pedidos web, pagos, devoluciones y transferencias entre sucursales.

Objetivo del ejercicio: seleccionar una arquitectura justificable a partir de requisitos, no a partir de preferencias tecnológicas.
