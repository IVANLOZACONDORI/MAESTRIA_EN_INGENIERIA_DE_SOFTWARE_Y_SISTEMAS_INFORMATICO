# Sistema seleccionado: SIGICI-RI

## Sistema Inteligente de Gestión de Incidentes de Ciberseguridad y Respuesta Institucional

Una institución requiere centralizar la gestión de incidentes de ciberseguridad, debido a que actualmente los reportes pueden recibirse mediante distintos medios y no existe un mecanismo único que permita conocer de manera inmediata el estado, severidad, responsable, evidencias, acciones realizadas y evolución de cada incidente.

El sistema SIGICI-RI permitirá registrar, clasificar, asignar, realizar seguimiento, escalar, resolver y cerrar incidentes de ciberseguridad. Asimismo, deberá mantener trazabilidad sobre las acciones efectuadas durante todo el ciclo de atención del incidente y controlar el acceso a la información según los permisos de los usuarios.

El sistema será utilizado principalmente por personal autorizado de la institución encargado de reportar, analizar, atender, supervisar y auditar incidentes de seguridad.

## Problema a resolver

La ausencia de una plataforma centralizada dificulta:

- conocer el estado actual de cada incidente;
- identificar oportunamente su nivel de severidad;
- determinar quién es responsable de su atención;
- conservar las evidencias relacionadas;
- conocer las acciones realizadas;
- mantener un historial completo del incidente;
- realizar seguimiento y escalamiento;
- generar información útil para supervisión y auditoría.

## Objetivo del caso de estudio

Definir y validar los requerimientos funcionales y no funcionales del sistema SIGICI-RI utilizando un agente especializado únicamente como mecanismo de validación inicial.

El agente deberá identificar posibles ambigüedades, contradicciones, duplicidades, requisitos incompletos, requisitos no verificables, inconsistencias entre RF y RNF y posibles omisiones.

La decisión final sobre aceptar, rechazar o modificar cada observación corresponde al estudiante.

En esta etapa no se seleccionará una tecnología, lenguaje de programación, framework, arquitectura ni motor de base de datos definitivo.
