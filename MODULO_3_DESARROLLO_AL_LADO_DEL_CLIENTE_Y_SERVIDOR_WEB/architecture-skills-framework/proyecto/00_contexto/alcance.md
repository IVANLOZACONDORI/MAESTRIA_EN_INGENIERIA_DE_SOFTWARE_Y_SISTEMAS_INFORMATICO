# Alcance

## Sistema

**SIGICI-RI – Sistema Inteligente de Gestión de Incidentes de Ciberseguridad y Respuesta Institucional**

## Alcance funcional

El sistema estará orientado a centralizar y controlar el ciclo de vida de los incidentes de ciberseguridad registrados dentro de una institución.

El alcance incluye:

- registro de incidentes de ciberseguridad;
- clasificación de incidentes según su nivel de severidad;
- asignación de responsables para la atención;
- actualización y seguimiento del estado del incidente;
- registro de acciones realizadas durante la atención;
- incorporación de evidencias relacionadas con el incidente;
- consulta del historial de cada incidente;
- búsqueda y filtrado de incidentes;
- generación de reportes;
- administración de usuarios;
- asignación de roles y permisos;
- control de acceso según el rol del usuario;
- registro de comentarios de seguimiento;
- escalamiento de incidentes;
- notificaciones asociadas a cambios relevantes;
- registro de fecha y hora de resolución;
- cierre de incidentes;
- conservación del historial de cambios;
- trazabilidad de las acciones realizadas.

## Usuarios considerados

El sistema podrá ser utilizado por personal autorizado de la institución, incluyendo:

- usuarios que reportan incidentes;
- responsables de atención;
- supervisores de seguridad;
- administradores del sistema;
- personal autorizado para auditoría y consulta.

Los permisos específicos de cada usuario deberán depender de su rol y nivel de autorización.

## Límites del alcance

En esta etapa del proyecto no se contempla:

- implementar físicamente el sistema;
- desarrollar código fuente;
- seleccionar definitivamente un lenguaje de programación;
- seleccionar un framework;
- seleccionar un motor de base de datos;
- seleccionar una arquitectura tecnológica definitiva;
- implementar infraestructura de producción;
- ejecutar pruebas de penetración reales;
- realizar acciones ofensivas sobre sistemas reales.

## Alcance del caso de estudio

El presente caso de estudio se limita a la definición y validación inicial de los Requerimientos Funcionales y Requerimientos No Funcionales del sistema SIGICI-RI mediante un agente especializado.

El agente será utilizado únicamente como mecanismo de apoyo para identificar problemas de ambigüedad, claridad, contradicción, duplicidad, completitud, verificabilidad, consistencia y posibles omisiones.

La decisión final sobre aceptar, rechazar o modificar cada observación corresponderá al estudiante.
