# Requisitos Funcionales Iniciales

## Sistema seleccionado

**SIGICI-RI – Sistema Inteligente de Gestión de Incidentes de Ciberseguridad y Respuesta Institucional**

## Requisitos funcionales

- **RF-01.** El sistema deberá permitir registrar un incidente de ciberseguridad.

- **RF-02.** El sistema deberá permitir clasificar los incidentes según su nivel de severidad.

- **RF-03.** El sistema deberá permitir asignar un responsable a cada incidente.

- **RF-04.** El sistema deberá permitir modificar el estado de un incidente durante su ciclo de atención.

- **RF-05.** El sistema deberá registrar las acciones realizadas durante la atención de cada incidente.

- **RF-06.** El sistema deberá permitir adjuntar evidencias relacionadas con un incidente.

- **RF-07.** El sistema deberá permitir consultar el historial completo de un incidente.

- **RF-08.** El sistema deberá permitir realizar búsquedas de incidentes utilizando diferentes criterios.

- **RF-09.** El sistema deberá permitir generar reportes de incidentes.

- **RF-10.** El sistema deberá permitir administrar usuarios.

- **RF-11.** El sistema deberá permitir asignar roles a los usuarios.

- **RF-12.** El sistema deberá controlar el acceso a las funciones según el rol del usuario.

- **RF-13.** El sistema deberá permitir registrar comentarios de seguimiento.

- **RF-14.** El sistema deberá permitir escalar un incidente a otro responsable.

- **RF-15.** El sistema deberá notificar los cambios relevantes relacionados con un incidente.

- **RF-16.** El sistema deberá permitir registrar la fecha y hora de resolución.

- **RF-17.** El sistema deberá permitir cerrar un incidente una vez solucionado.

- **RF-18.** El sistema deberá conservar el historial de cambios realizados sobre cada incidente.
